# 🧠 Deep Learning Projects

This repository contains a collection of beginner-friendly projects in **Computer Vision** and **Image Processing** using Python, OpenCV, and related libraries. Each file demonstrates a different concept and practical use case.

---

## 📂 Projects Included

### 1. 🎨 Color Detection in Images
- Detects specific colors (Red, Green, Blue, etc.) in images or real-time video.
- Uses HSV color space and masks to highlight selected colors.

### 2. 👤 Face Detection in Photos or Videos
- Detects human faces in images or live video streams.
- Implements Haar cascades or DNN models from OpenCV.
- Draws bounding boxes around detected faces.

### 3. 🖼️ Edge Detection in Images
- Applies **Canny Edge Detection** to extract edges and outlines from images.
- Useful for object recognition, segmentation, and preprocessing tasks.

### 4. 🎥 Object Tracking in a Video
- Tracks moving objects in real-time video.
- Uses contour detection and bounding boxes to follow object motion.
- Can be adapted for multi-object tracking.

### 5. 🔍 QR Code Scanner
- Scans and decodes QR codes from images or webcam feed.
- Extracts and displays the text/URL contained in the QR code.

---
